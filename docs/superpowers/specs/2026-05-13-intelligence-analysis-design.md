# 智能分析模块设计

## Why

图书馆数据规模已达千万级别，现有分析功能不足以挖掘数据价值。需要提供关联分析和馆藏优化建议，帮助图书馆优化馆藏和提升服务质量。

## What Changes

### 1. 新增"智能分析"页面

- 位置：侧边栏"数据分析"分组
- Tab切换：关联分析 | 馆藏优化

### 2. 关联分析功能

#### 数据范围

- 基于同一读者的历史借阅记录
- 时间范围可配置：近1年/2年/全部

#### 算法参数

- 最小支持度阈值：5%（可配置）
- 最小置信度阈值：10%（可配置）

#### 展示方式

- **主视图**：力导向图（Force-directed graph）
- **备选视图**：配对列表

#### 交互功能

| 功能     | 说明          |
| ------ | ----------- |
| 缩放/拖拽  | 鼠标滚轮缩放，拖拽画布 |
| 搜索定位   | 输入书名高亮定位节点  |
| 按分类着色  | 不同分类用不同颜色区分 |
| 拖拽固定   | 拖拽节点后可固定位置  |
| 动态模拟控制 | 调整力度、距离等参数  |

### 3. 馆藏优化建议

#### 筛查条件

| 问题类型 | 定义        | 阈值   |
| ---- | --------- | ---- |
| 从未被借 | 历史记录中无借阅  | -    |
| 低频借阅 | 借阅次数低于阈值  | < 5次 |
| 长期闲置 | 超过N个月未被借阅 | 4个月  |

#### 界面布局

```
┌────────────────────────────────────────────────────┐
│  [问题类型▼] [分类▼] [排序▼] [搜索...]              │
├────────────────────────────────────────────────────┤
│ 图书名称 │ 分类 │ 问题类型 │ 最后借阅 │ 借阅次数   │
├────────────────────────────────────────────────────┤
│ 书名A   │ 文学 │ 从未被借  │   -      │    0      │
│ 书名B   │ 科技 │ 低频借阅  │ 2024-03  │    2      │
│ 书名C   │ 历史 │ 长期闲置  │ 2024-01  │    3      │
└────────────────────────────────────────────────────┘
```

## Impact

- 前端：新增 `IntelligenceView.vue` 页面
- 后端：新增 `/api/intelligence/` 路由
- 图表：D3.js 力导向图

## ADDED Requirements

### Requirement: 关联分析

系统应提供基于读者借阅历史的图书关联分析

#### Scenario: 力导向图展示

- **WHEN** 用户进入关联分析Tab
- **THEN** 显示力导向图，节点=图书，边=关联关系

#### Scenario: 节点交互

- **WHEN** 用户点击节点
- **THEN** 高亮该图书的所有关联，显示详情弹窗

#### Scenario: 搜索定位

- **WHEN** 用户输入书名搜索
- **THEN** 定位并高亮对应节点

### Requirement: 馆藏优化

系统应提供馆藏问题图书的筛查和建议

#### Scenario: 问题筛查

- **WHEN** 用户打开馆藏优化Tab
- **THEN** 显示问题图书列表，包含问题类型

#### Scenario: 筛选排序

- **WHEN** 用户切换筛选条件
- **THEN** 列表实时更新

## Technical Implementation

### 后端API

```
GET /api/intelligence/correlation
  - year_range: 1|2|all (时间范围)
  - min_support: float (最小支持度)
  Response: { nodes: [...], links: [...] }

GET /api/intelligence/collection-optimization
  - never_borrowed: bool (从未被借)
  - low_freq_threshold: int (低频阈值)
  - idle_months: int (闲置月数)
  Response: { total: int, list: [...] }
```

### 前端组件

- `IntelligenceView.vue` - 主页面
- `CorrelationChart.vue` - 力导向图组件
- `OptimizationList.vue` - 优化建议列表
